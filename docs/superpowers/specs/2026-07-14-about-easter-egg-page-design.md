# “关于”彩蛋页设计

## 目标

新增一个低调的 Demo 叙事页面，把 README 的制作初衷整理成更适合现场展示的故事。它是补充材料，不与版本情报、版本预热、问派蒙、能力预览和发行洞察并列。

## 入口与路由

- 新页面路由为 `/about`，页面标题为“关于 / About”。
- 入口位于桌面侧栏底部的语言切换器正上方，使用较小字号和较弱视觉权重，并与主导航保持距离。
- 入口不加入主导航数组，也不进入移动端底部主导航，以保留彩蛋属性。
- 当用户位于 `/about` 时，入口可以显示轻量选中状态，但不采用主功能页的高亮规格。

## 内容结构

页面随全局语言偏好切换中英文，内容完全静态，凝练 README 的“制作初衷”为四段：

1. **为什么需要它**：原神世界观庞大，玩家需要快速理解或回忆概念。
2. **为什么要控制剧透**：答案不能以牺牲探索乐趣和未来剧情体验为代价。
3. **为什么是派蒙**：派蒙本就是旅行者的向导，适合作为兼具知识、语气与陪伴感的 AI 载体。
4. **为什么在此时尝试**：至冬临近、伏笔逐步收束，既要回应旧线索，也要为持续运营铺设新期待。

结尾用一句简短的设计命题收束：让玩家更容易进入故事，而不是替玩家经历故事。

## 视觉方向

- 延续现有提瓦特档案、向导手记和纸张质感，不引入新的品牌体系。
- 使用一个主叙事栏和四个编号段落，避免营销落地页式卡片堆叠。
- 保持正文高对比度；装饰只用于边框、编号、批注和淡化的星轨纹样。
- 页面在窄屏下改为单栏；不添加复杂动画、图片生成或交互组件。

## 实现边界

- 新增 `app/about/page.tsx`。
- 在 `components/app-shell.tsx` 的 `game-nav-tools` 中加入次级入口。
- 在 `app/globals.css` 中添加页面及入口样式。
- 添加源码级 UI 测试，确认 `/about` 内容、双语文案、入口位置以及它未进入主导航和底部导航。
- 不新增 API、状态存储、埋点、数据文件或第三方依赖。

## 验收

- 桌面侧栏中“关于”位于语言切换器上方，视觉上明显低于主功能页。
- `/about` 可直接访问，并随语言切换显示对应内容。
- 移动端页面排版完整，关于入口不占用底部主导航名额。
- 类型检查、相关测试和生产构建通过。
