# 问派蒙线索标题排版修复设计

## 问题

“问派蒙”回答中的线索区标题栏同时匹配了通用的 `.claim-list > div` 三列网格规则和专用的 `.clue-ledger-heading` 横向规则。通用规则的选择器优先级更高，导致标题被限制在 18px 的第一列内，中文逐字换行。

## 方案

将通用线索条目选择器收窄为 `.claim-list > div:not(.clue-ledger-heading)`，使三列网格只作用于包含图标、线索正文和事实边界徽章的实际条目。标题栏继续使用已有的 flex 布局：桌面端标题在左、边界说明在右。

在窄屏断点中让标题栏改为纵向排列，并将说明文字左对齐，避免标题和说明在有限宽度内互相挤压。

## 范围

- 只修改 `app/globals.css` 中线索区相关选择器和移动端覆盖规则。
- 不修改回答数据、组件结构、文案、资料来源区或其他卡片样式。
- 保留现有羊皮纸色背景、双层边框和事实边界徽章。

## 验证

- 增加源码级回归断言，确保标题栏被排除在三列网格规则之外。
- 运行相关测试、类型检查和构建。
- 在桌面和移动视口检查：标题不再逐字换行，说明可读，线索正文与徽章仍按三列结构排列。
