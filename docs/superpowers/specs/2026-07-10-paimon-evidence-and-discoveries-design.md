# 派蒙线索体验与本地探索彩蛋设计

## 目标

让带证据的回答首先像派蒙整理出的冒险线索，而非技术日志；同时加入不会剧透、不依赖账号或网络、可在面试现场稳定演示的轻量探索彩蛋。

## 范围

本轮实现五项相互协作的体验：

1. 回答卡把关键结论组织为“派蒙查到的线索”，并显式区分“已确认 / 合理推测 / 尚未公开”。
2. 检索流水改名为“考据记录”，在回答完成后默认收起。
3. 首页展示每天稳定的一条“今日派蒙小纸条”。
4. 关系图浏览收集星图碎片，三个不同节点解锁可分享的旅行者线索卡。
5. 连续点击站点派蒙徽记五次解锁一次性、无侵入的派蒙吐槽卡。

不新增账户、服务端状态、第三方素材、联网依赖或原始问题存储。发行洞察、内容数据模型和问答服务端行为保持不变。

## 体验设计

### 回答线索卡

`AnswerCard` 保留答案正文、置信度、引用、延伸阅读与反馈。关键依据区升级为“派蒙查到的线索”：每条依据显示一个明确的事实边界徽章。

- `confirmed` 显示“已确认”。
- `narrative_implication` 显示“合理推测”。
- `community_speculation`、`demo_hypothesis` 或未映射状态显示“尚未公开 / 仍待证实”，不得伪装成确认事实。

引用区保留为“资料来源”。回答成功时，trace 不再抢占正文：它被收进默认关闭的“考据记录”，但加载过程中仍默认展开，让玩家看到派蒙正在查资料。

### 今日派蒙小纸条

添加一份人工审阅的本地小纸条目录。每条只陈述已实装、无剧透的事实，并可选择跳转到已有预热或问答入口。按用户本地日期用确定性索引选取内容，因此同一天稳定、跨天自动变化，无需存储每日访问事件。

### 巡游星图与线索卡

关系图节点首次被选中时，向本地探索状态登记节点 ID。收集三个不同节点解锁线索卡；卡片概述已发现节点数和可追问的未知边界，不生成或暴露未来剧情。解锁后提供 Web Share API；不支持时复制同一段可读文本。状态保存在 localStorage，存储不可用时在当前会话内正常工作。

### 派蒙吐槽彩蛋

站点品牌徽记正常仍是首页链接。每次激活都会递增本地计数；第 5 次触发一次性对话卡并写入已发现状态。点击、Enter 和 Space 均可触发计数，且不会阻断链接的默认导航。彩蛋只使用原创派蒙口吻文案。

## 组件与数据边界

```text
data/paimon-notes.ts ──────> TodayPaimonNote ──────> 首页
                                  ↑
lib/traveler-discoveries.ts ─> DiscoveriesProvider ─> 星图 / 品牌徽记 / 线索卡
                                  ↑
                              localStorage（可失败）

AnswerCard ──> 线索卡 + 资料来源
TraceTimeline ──> 考据记录（回答完成后折叠）
```

- `lib/traveler-discoveries.ts`：纯函数与持久化协议，包括安全读取、不同节点去重、三节点解锁、日更索引和分享文案。
- `components/discoveries-provider.tsx`：将状态与动作提供给页面、关系图与导航。
- `components/today-paimon-note.tsx`：只负责展示当天的受控内容。
- `components/traveler-clue-card.tsx`：只负责解锁反馈与分享降级。
- `components/app-shell.tsx`：品牌徽记计数和一次性彩蛋弹层。
- `components/snezhnaya-graph.tsx`：节点首次选择时登记探索进度。

## 失败处理与可访问性

- localStorage 不可用：使用内存状态，不显示错误，不丢失当前页面内的收集反馈。
- Web Share API 不可用或被拒绝：回退到 Clipboard API；剪贴板不可用时展示可复制的文案。
- 不存在的节点 ID、重复节点和超过三个节点均幂等处理。
- 所有可交互控件有可读标签、键盘可达焦点和 `aria-live` 解锁提示；动画遵从 `prefers-reduced-motion`。

## 验证

- 为本地探索纯函数测试日期稳定选择、去重收集、三节点解锁、持久化降级与分享文案。
- 为 UI 源码测试验证玩家可见文案“派蒙查到的线索”“考据记录”及三种证据边界存在。
- 运行 `npm test`、`npm run typecheck` 与 `npm run build`。
- 本地预览检查：回答完成后的 trace 默认收起；访问三个图谱节点后显示线索卡；刷新后本地进度保留；彩蛋只弹出一次。

## 非目标

- 不将彩蛋做成账号体系、成就等级或服务端任务。
- 不使用游戏原声、角色语音、拆包资源或未授权素材。
- 不改变模型回答、证据检索、剧透令牌或隐私授权机制。
